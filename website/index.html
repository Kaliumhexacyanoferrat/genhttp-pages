    Need a server? Ask for it.

    Your site runs on a real web server, so it can have a server part. Ask the dashboard's agent for it in Change, or your own agent through MCP: it is built beside your pages, which call it with fetch('api/…'). Ask for the server, not for pages: the pages stay in your repository, and a push replaces them and keeps the server.
